# P1_Cafemanagementsystem

 Developed a Python program enabling customers to place multiple orders and calculate the total
 bill interactively.
 Key Features:Dynamic order management using Python dictionaries.
 Conditional statements to handle user interactions and decision-making.
 Calculation of total order amount in real-time.
 User-friendly prompts for seamless ordering experience.
 Technologies Used: Python, Dictionaries, Conditional Statements
